# Model Tells

Reference for the fiction-criticism skill. Read when the author is or may be a machine - above all before self-critique of your own drafts.

Model-written fiction fails in ways ordinary criticism under-catches, because the failures look like polish: the sentences are clean, the structure is tidy, nothing is wrong in a way a line edit would catch. Six lenses. Hunt each one on purpose; none of them announces itself.

---

## 1. Comedy: wiring and lineage

Does the funny build - setups that pay off later, callbacks that compound, escalation with consequences - or does each joke live and die in its own sentence? And whose comedy is it? Models default to internet-millennial snark: the knowing aside, the quip that laughs at itself. If that register wasn't chosen, name it as a squatter, and name what the material's actual tradition and audience would be.

Test: list every joke and mark which ones depend on something earlier. If none do, the comedy is decoration, not structure.

## 2. Plot as plan

Ask what the structure is for: the causal chain, the emotional waveform, the argument the sequence makes. A model produces chapters in which things merely happen, at uniform pressure, in shufflable order.

Test: mentally reorder the middle. If it reorders without loss, that is a significant finding, not a quibble.

## 3. The safe choice

Averageness is a diagnosable defect. Find the places the work took the expected exit - the obvious arc, the inoffensive turn, the ending nobody could object to - and say what bolder road was available, as a direction, never as prose. A work that risks nothing has already failed a reader who wanted anything.

Test: at each major turn, ask what the reader expected. If the text did exactly that, mark it.

## 4. Template furniture

Borrowed activities (mini golf, the sunset walk), borrowed registers (tender vulnerability on a bench as the default for intimacy), committee names ("The [Noun]").

Test, to run and report: recast the scene with different characters. If it still works, it belonged to nobody.

## 5. The demo reel

Ensemble scenes that deal one beat per character, each displaying their function; expositions that reveal the whole machine on first contact. Trading cards are not a cast.

Test: what was withheld for later, and did anyone behave against their function? If nothing and no one, the scene is a demonstration.

## 6. Narrated machinery

The text doing the reader's job: naming its own subtext, glossing its own symbols, describing a character's evasion instead of committing it ("she files it away"). Where the narration explains what the scene showed, the finding is the explanation itself.

Test: underline every sentence that interprets rather than renders. Each one is a candidate finding.

---

## Discipline

These lenses judge the work, not its origin. A human can commit every one, and a detection score is never evidence for or against them. When critiquing a person's writing, name the failure and its location; never speculate about whether they used a model.

Apply them with the same discipline as any other finding: locate, name the level, tag the severity, ground the claim. The repairs belong to the storytelling skill; `/skills/storytelling/references/what-models-get-wrong.md` carries the tests and fixes for the overlapping drafting defaults (the explaining narrator, the aphoristic button, mechanizing the story, and others).
