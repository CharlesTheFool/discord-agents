# Genre Modules

Genre- and style-specific craft modules for the storytelling skill. Read the relevant one when a project has a defined genre. A module can override the skill's default approach where a genre genuinely demands something different.

Every module describes how a genre's mechanics tend to work and what craft problems it poses. None of it is prescriptive. The particular story - its characters, voice, constraints, and emotional logic - always takes priority over genre convention. These modules widen the toolkit and help diagnose problems; they don't impose templates.

## Available

- `comedy.md` - how humor works, farce, ensemble comedy, dark and transgressive comedy, prose micro-mechanics, register blending, drafting templates.

## Adding a module

Each module should cover what the genre demands that differs from default craft, its specific failure modes, actionable techniques, and drafting and revision tools. Add one when a kind of project keeps coming up.
